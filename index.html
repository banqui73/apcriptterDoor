Cómo funciona
1️⃣ El emisor crea una sala y comparte el código
2️⃣ El receptor introduce el código para unirse
3️⃣ Se negocia conexión WebRTC directa via Firebase
4️⃣ Se genera clave AES-GCM-256 efímera para la sesión
5️⃣ Los datos viajan cifrados P2P, sin pasar por ningún servidor
⚠️ La señalización inicial usa Firebase Realtime DB pero los datos del archivo nunca pasan por Firebase. Si WebRTC no puede hacer P2P directo (redes muy restrictivas), el canal se cierra.

⚡ SDK — Integración rápida para tu juego/app
Copia este script en tu HTML. Funciona desde cualquier dominio, incluyendo GitHub Pages.
<!-- En tu juego o web --> <script src="https://banqui73.github.io/apcriptterDoor/aegis-sdk.js"></script> <script> // Inicializar SDK const aegis = new AegisSDK({ apiKey: 'tu-api-key' }); // Cifrar datos del juego (puntuaciones, save states, etc.) const encrypted = await aegis.encrypt('{"score":9999,"level":42}', 'miClave'); // Descifrar const data = await aegis.decrypt(encrypted, 'miClave'); // Transferencia P2P entre jugadores const room = await aegis.createRoom(); room.onFile = (file, name) => console.log('Archivo recibido:', name); await room.sendFile(myFile); </script>
Tu clave de API
Inclúyela como header X-Aegis-Key o en el constructor del SDK.
POST
/api/v1/encrypt
Cifra texto o datos en base64 con AES-CBC-128 (free) o algoritmos avanzados (premium).
// Con SDK (recomendado) const result = await aegis.encrypt(data, password); // Con fetch directo (implementación Firebase) fetch('https://TUDB-default-rtdb.firebaseio.com/aegis_api/req.json', { method: 'POST', body: JSON.stringify({ action:'encrypt', apiKey, data, password }) }).then(r=>r.json()).then(console.log);
POST
/api/v1/transfer/create
Crea sala de transferencia P2P. Devuelve roomId para compartir con el receptor.
const room = await aegis.createRoom(); console.log(room.id); // "ABCD1234" room.onConnected = () => console.log('Peer conectado'); room.onProgress = (pct) => updateUI(pct); room.onComplete = () => console.log('¡Enviado!');

/api/v1/status
