API Pública AegisPattern
Demo funcional de cifrado AES-CBC ejecutada 100% en el navegador. Sin servidor, sin instalación.
✅ Funcional en browser · Sin backend · GitHub Pages compatible 🔒 Solo AES-CBC-128 · Máx 1MB · Solo texto
Tu clave de API (local)
Esta clave se genera localmente y se almacena en tu sesión. Inclúyela en el header X-Aegis-Key al llamar a una implementación de servidor propia.
POST
/api/v1/encrypt
Documentación de referencia. Implementa este endpoint en tu propio servidor con la lógica AES-CBC de abajo. GitHub Pages no soporta backends dinámicos.
// Solicitud de referencia fetch('https://TU-SERVIDOR.com/api/v1/encrypt', { method: 'POST', headers: { 'Content-Type': 'application/json', 'X-Aegis-Key': 'tu-api-key-aqui' }, body: JSON.stringify({ data: "Texto o base64 a cifrar", password: "contraseña-secreta", format: "base64" // "base64" | "hex" }) }) .then(r => r.json()) .then(res => { console.log(res.encrypted); // string base64 console.log(res.algo); // "AES-CBC-128" console.log(res.overhead); // bytes de IV });
POST
/api/v1/decrypt
Descifra datos cifrados con el mismo algoritmo. Requiere la misma contraseña y el output previo.
fetch('https://TU-SERVIDOR.com/api/v1/decrypt', { method: 'POST', headers: { 'Content-Type': 'application/json', 'X-Aegis-Key': 'tu-api-key-aqui' }, body: JSON.stringify({ encrypted: "base64-del-archivo-cifrado", password: "contraseña-secreta" }) }) .then(r => r.json()) .then(res => console.log(res.decrypted));
GET
/api/v1/status
Consulta el estado de tu clave API: peticiones usadas, límite y tiempo de reset.
fetch('https://TU-SERVIDOR.com/api/v1/status', { headers: { 'X-Aegis-Key': 'tu-api-key-aqui' } }) .then(r => r.json()) .then(res => { console.log(res.used); // peticiones usadas console.log(res.limit); // 50 console.log(res.reset_in); // segundos hasta reset });
